# Как включить форму воронки — пошагово

Пока переменные не заданы, человек проходит все 12 шагов, а на отправке
получает ошибку. Делается один раз.

## Выберите, куда получать заявки

Достаточно **одного** варианта — форма заработает.

| | Telegram | Google Таблица |
|---|---|---|
| Время | ~2 минуты | ~15 минут |
| Что нужно уметь | переписываться в Telegram | базово ориентироваться в Google |
| Куда падают заявки | сообщением на телефон | строкой в таблице + письмо |
| Окна разрешений Google | нет | да |

**Если не работали с Google Таблицами — берите Telegram** (часть А-Т ниже).
Google-вариант (часть А-G) можно подключить позже дополнительно: если настроены
оба, заявка уйдёт и туда, и туда.

---

# Часть А-Т. Telegram (2 минуты)

**1. Создайте бота**
В Telegram найдите **@BotFather** → напишите ему `/newbot` → он спросит имя
бота (любое, например `Selena Leads`) → потом имя пользователя, оно должно
заканчиваться на `bot` (например `selena_leads_bot`).

В ответ он пришлёт строку вида `8123456789:AAF...` — это **`TELEGRAM_BOT_TOKEN`**.
Никому её не показывайте: кто владеет токеном, тот управляет ботом.

**2. Узнайте свой ID**
Найдите в Telegram бота **@userinfobot** → нажмите Start. Он ответит числом
вроде `123456789` — это **`TELEGRAM_CHAT_ID`**.

**3. Напишите своему боту**
Откройте бота, которого создали в шаге 1, и нажмите **Start**.
Это обязательно: Telegram не даёт боту писать первым.

Готово. Дальше — часть Б (переменные на Vercel).

---

# Часть А-G. Google Таблица (~15 минут, необязательно)

Эта ссылка — «почтовый ящик», куда сайт складывает заявки.

**1. Создайте таблицу**
Google Диск → Создать → Google Таблицы. Переименуйте нижнюю вкладку листа в
`Inbound Audit Leads` (точно так, с большой буквы).
Заголовки колонок создадутся сами при первой заявке. Код таблицы копировать
не нужно — скрипт будет жить внутри неё.

**2. Откройте редактор скрипта**
В этой же таблице: меню **Расширения → Apps Script**.

> ⚠️ Именно отсюда, изнутри таблицы. Тогда скрипт «привязан» к ней, и Google
> выдаст доступ **только к этой одной таблице**. Если создать скрипт отдельно
> через script.google.com, привязки не будет и он не заработает.

Удалите всё, что там есть, и вставьте содержимое файла `google-apps-script/Code.gs`
из репозитория. Сохраните (значок дискеты).

**2б. Ограничьте разрешения**
Слева **Настройки проекта** (шестерёнка) → поставьте галочку
**«Показывать файл манифеста appsscript.json»**. Он появится в списке файлов
слева — откройте и замените его содержимое на файл
`google-apps-script/appsscript.json` из репозитория. Сохраните.

Именно этот файл говорит Google: «дай доступ только к этой таблице и только на
отправку писем». Без него Google запросит доступ ко всем таблицам.

**3. Впишите настройки скрипта**
Там же, **Настройки проекта** → внизу **Свойства скрипта** →
**Добавить свойство**. Нужно три штуки:

| Свойство | Значение |
|---|---|
| `SHARED_SECRET` | `68c732de998cbc85dc8a0cd478428e9fe850e888f6b95d7f486464f667714b02` |
| `SHEET_NAME` | `Inbound Audit Leads` |
| `NOTIFICATION_EMAIL` | ваша почта — туда будут падать письма о заявках |

**4. Опубликуйте скрипт**
Кнопка **Развернуть → Новое развёртывание** → тип **Веб-приложение**.
Два поля обязательно так:
- **Запуск от имени:** Я (ваш аккаунт)
- **У кого есть доступ:** Все

Нажмите **Развернуть**. Google попросит разрешения — согласитесь.

Что именно вы разрешаете (после шага 2б):
- **эта таблица** — читать и писать строки заявок. Другие ваши файлы скрипту
  недоступны;
- **отправка писем** — только отправка, на адрес из `NOTIFICATION_EMAIL`.
  Читать вашу почту это разрешение не позволяет.

Отозвать в любой момент: Google Аккаунт → Безопасность → Сторонние приложения.

**Скопируйте ссылку**, которая появится. Она заканчивается на `/exec` —
это и есть `APPS_SCRIPT_WEBHOOK_URL`.

# Часть Б. Вписать переменные на Vercel (3 минуты)

Vercel → ваш проект → **Settings** → **Environment Variables**.
Добавляете по одной: Name (имя) → Value (значение) → **Save**.

**Всегда нужны эти две:**

| Name | Value |
|---|---|
| `ALLOWED_ORIGIN` | `https://villaops.selenasystems.com` |
| `IP_HASH_SALT` | `bc6c20494d3051d178d9458581f47dd2` |

**Если выбрали Telegram — ещё две:**

| Name | Value |
|---|---|
| `TELEGRAM_BOT_TOKEN` | строка от @BotFather |
| `TELEGRAM_CHAT_ID` | число от @userinfobot |

**Если выбрали Google — вместо них эти две:**

| Name | Value |
|---|---|
| `APPS_SCRIPT_WEBHOOK_URL` | ссылка на `/exec` из части А-G |
| `APPS_SCRIPT_SHARED_SECRET` | `68c732de998cbc85dc8a0cd478428e9fe850e888f6b95d7f486464f667714b02` |

Можно настроить и то, и другое — тогда заявка придёт обоими способами.

**Две частые ошибки:**
- `ALLOWED_ORIGIN` — **без слэша в конце**. Не `…com/`, а `…com`.
  Если сайт открывается ещё и по другому адресу, перечислите через запятую:
  `https://villaops.selenasystems.com,https://bali-os-villa-2026.vercel.app`
- `APPS_SCRIPT_SHARED_SECRET` на Vercel и `SHARED_SECRET` в Google должны
  совпадать символ в символ. Это пароль между сайтом и таблицей.

# Часть В. Перевыпустить сайт (30 секунд)

Переменные не подхватываются сами. Vercel → вкладка **Deployments** →
у верхнего деплоя меню «…» → **Redeploy** → подтвердить.

---

# Часть Г. Проверить, что заработало

1. Откройте `https://villaops.selenasystems.com/score/`, пройдите анкету
   до конца и отправьте.
2. Должно появиться **«Request received»**, а не сообщение об ошибке.
3. Заявка придёт: в Telegram — сообщением от вашего бота; в Google — новой
   строкой в таблице и письмом.

**Если написано «Request origin not allowed»** — дело в `ALLOWED_ORIGIN`:
скорее всего лишний слэш в конце или адрес не тот, с которого вы открыли сайт.

**Если написано, что заявка не сохранилась и просит попробовать позже** —
не сработал ни один способ доставки:
- Telegram: проверьте, что нажали **Start** у своего бота, и что `TELEGRAM_CHAT_ID` —
  это число, а не имя пользователя;
- Google: ссылка должна оканчиваться на `/exec`, доступ — «Все», секрет —
  одинаковый с обеих сторон.

## Необязательное

`PAGESPEED_API_KEY` — ключ Google PageSpeed. Без него бесплатный аудит сайта
работает и показывает наши собственные измерения скорости; с ключом
добавляются ещё и лабораторные метрики Google.
Берётся здесь: Google Cloud Console → APIs & Services → Credentials →
Create credentials → API key, затем включить «PageSpeed Insights API».

## Если меняете секрет

Новое значение нужно вписать **в двух местах**: Script Properties в Google и
переменную на Vercel. После этого в Google: Развернуть → Управление
развёртываниями → Изменить → новая версия. И Redeploy на Vercel.
